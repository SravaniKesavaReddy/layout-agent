# AI Layout Editor

## 🚀 Project Overview
This is an AI-powered layout editor where users can edit UI designs using natural language.

## 🧠 Features
- Chat-based UI editing
- AI-powered layout transformation
- Live wireframe preview
- JSON structure visualization

## 🛠 Tech Stack
- React
- Node.js
- Express
- Groq AI
- TailwindCSS

## ⚙️ How it works
User input → AI model → JSON layout update → UI render
